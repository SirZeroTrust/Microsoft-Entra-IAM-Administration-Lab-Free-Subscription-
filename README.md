* Microsoft Entra ID IAM Lab

This lab demonstrates core Identity and Access Management (IAM) tasks using Microsoft Entra ID in a cloud environment.

**Skills Demonstrated

- Configured and managed Microsoft Entra ID users, groups, and administrative roles within a cloud identity environment.
- Implemented Multi-Factor Authentication (MFA) policies to strengthen authentication security.
- Created and managed security groups to support Role-Based Access Control (RBAC) and group-based access management.
- Assigned Microsoft Entra ID administrative roles using the principle of least privilege.
- Configured Administrative Units to demonstrate delegated administration and department-level identity management.
- Simulated IAM workflows including user onboarding, offboarding, access provisioning, and application authorization.
- Applied identity governance concepts through role delegation, access control, and lifecycle management.
